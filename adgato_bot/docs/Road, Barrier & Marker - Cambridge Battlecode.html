Property Value HP 30 Base cost 3 Ti Scaling 1% ​ <#marker> Marker Marker A tile containing a single *unsigned 32-bit integer* that can be read by any allied unit. Building a marker is completely free and does *not* cost action cooldown — you may place at most one marker per round. Any team may build over markers, destroying them. Property Value HP 1 Cost Free Markers are the *only form of communication* between allied units. Global variables are not shared between |Player| instances — each unit has its own isolated Python environment. All units (core, builder bots, and turrets) can place markers — not just builder bots.
